请求策略

选择如何处理各供应商请求中的提示词缓存。

策略预览

阈值内原样保留；超过后，每次请求都在固定的后续消息起点加入新标记，早期缓存前缀不变。不是每 N 轮循环一次。需要完整历史；显式缓存与原缓存键保留，OpenAI explicit-only 专项暂停。

Token 是估算值，并按首次越过阈值的整个用户轮处理；该轮中阈值前的部分文本也可能不再命中缓存。

扰动文本会进入模型上下文，可能影响模型理解。

扰动形式的限制

所有样式都进入模型上下文，不保证无语义影响或零命中。空白不保证节省 Token；需要现有非空、未签名的首个文本块，否则报错而不创建纯空白块。文本扰动模式不会额外开启 OpenAI 专有关闭参数。

协议适配范围

Magpie 当前协议：Anthropic Messages、Chat Completions、Responses、Gemini；兼容接口使用 Chat 适配。

扩展格式：Bedrock Converse、Cohere v2、Ollama Chat / Generate、Vertex Gemini。需要宿主传入对应原生协议；本插件不会创建新网关路由。

协议专项设置Gemini 缓存引用与 Responses 显式模式

Gemini 缓存引用

引用可能代替整段上下文；网关无法自动取回其内容。

删除引用不会恢复其中的上下文。请确认请求已经包含完整对话、提示词和工具定义。

OpenAI Responses 专项

仅用于“只关闭显式缓存”模式且供应商已确认支持；文本扰动模式会暂停此专项。旧模型和兼容接口可能不支持。

诊断

日志记录所采取的措施及缓存 token 数，不包含提示词。缺少统计不等于零命中。

随机标记不能保证零缓存命中，也可能增加费用和延迟。保存后从下一次请求生效。
